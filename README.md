# Автоматическая активация виртуального окружения в PowerShell для VSCode

## 1. Открытие PowerShell в VSCode
Откройте терминал PowerShell внутри VSCode.

## 2. Открытие или создание профиля PowerShell
Выполните следующую команду, чтобы открыть (или создать) профиль PowerShell:

```powershell
notepad $PROFILE
```

## 3. Добавление кода для автоматической активации виртуального окружения
В открывшемся файле `notepad` добавьте следующий код:

```powershell
if ($env:VIRTUAL_ENV) {
    . "$env:VIRTUAL_ENV\Scripts\Activate.ps1"
}
```

## 4. Сохранение изменений
Сохраните и закройте файл `notepad`.

## 5. Применение изменений
Перезапустите терминал PowerShell или перезапустите VSCode, чтобы изменения вступили в силу.

Теперь при запуске PowerShell внутри VSCode виртуальное окружение будет активироваться автоматически!
